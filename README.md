# El Talar — Comercial Legumbres SRL

Landing informativa de El Talar, la marca de Comercial Legumbres SRL:
legumbres a granel, envasadas con marca propia y venta mayorista.

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4

## Desarrollo

```bash
npm install
npm run dev
```
